# Scope and ethics

This repository is a **personal field notebook** published for education.

## Allowed use

- Studying for OSCP-style exams and practical certifications
- Authorized lab practice (HTB, Proving Grounds, OffSec labs you are licensed for, your own VMs)
- Building your own checklists and automation on top of these patterns

## Not allowed

- Pointing these techniques at systems without authorization
- Treating any note as an exam answer key
- Re-uploading OffSec course material or exam content into this tree

## Content policy for this public tree

| Included | Excluded |
|----------|----------|
| Methodology, checklists, decision trees | Exam host notes / proof flags |
| Generic commands with placeholders | Live VPN configs / real engagement IPs |
| “From Your Boxes” lessons (HTB/PG/personal) with redacted secrets | Full writeup dumps, course exercise dumps |
| `fill-variables.py` helper | Applied Variable values with real IPs |

If you find a real credential, exam artifact, or copyrighted course excerpt, open an issue or PR to remove it.
