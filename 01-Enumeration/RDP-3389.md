# RDP - Port 3389

## Connect

```bash
# xfreerdp (preferred)
xfreerdp /v:$IP /u:user /p:REDACTED /cert-ignore +clipboard /dynamic-resolution

# With drive sharing
xfreerdp /v:$IP /u:user /p:REDACTED /cert-ignore +clipboard /drive:REDACTED,/tmp

# Specific screen size
xfreerdp /v:$IP /u:user /p:REDACTED /cert-ignore /w:1920 /h:1080

# rdesktop (alternative)
rdesktop $IP -u user -p password
```

## Pass the Hash

```bash
xfreerdp /v:$IP /u:user /pth:REDACTED /cert-ignore +clipboard /dynamic-resolution
```

Requires Restricted Admin mode or specific registry key enabled on target.

## Brute Force

```bash
hydra -l user -P /usr/share/wordlists/rockyou.txt rdp://$IP
nxc rdp $IP -u user -p password
nxc rdp $IP -u users.txt -p REDACTED --continue-on-success
```

## Nmap

```bash
nmap --script rdp-enum-encryption,rdp-ntlm-info -p 3389 $IP
```

## Vulnerability Checks

```bash
# BlueKeep (CVE-2019-0708)
nmap --script rdp-vuln-ms12-020 -p 3389 $IP

# Or with nxc
nxc rdp $IP -u '' -p '' --nla-screenshot
```

## Tips

- `rdp-ntlm-info` script leaks domain name, hostname, and OS version.
- If NLA (Network Level Authentication) is disabled, you can connect without valid creds to see the login screen.
- RDP sessions may have cached credentials or open applications.
- Check for multiple users — might be able to hijack sessions.

## From Your Boxes

> **Hokkaido** (PG/Windows) — RDP used for final access after changing a tier-1 admin password via RPC. The `rdp-ntlm-info` nmap script confirmed domain name `hokkaido-aerospace.com`, computer name `DC`, and OS version before any authentication.
> - What worked: `xfreerdp /u:molly.smith /p:'REDACTED' /v:TARGET_IP +clipboard /drive:/home/kali` — note the `/drive:` flag for file transfer
> - Lesson: RDP with `/drive:` sharing is the easiest way to transfer files when you have RDP access. Also, run cmd as admin for privesc commands.

> **Hermes (OSCP A)** (Course) — RDP nmap scripts (`rdp-ntlm-info`) leaked `Target_Name: OSCP`, `NetBIOS_Computer_Name: OSCP`, and `Product_Version: 10.0.19041` without any credentials.
> - What worked: `nmap --script rdp-ntlm-info -p 3389 $IP`
> - Lesson: `rdp-ntlm-info` is free recon — always run it. It reveals domain name, hostname, and exact OS build.
